Keep your Mac fast, clean and safe.

Sentinel lives in your menu bar. It finds apps you are not using, cleans old caches, removes apps with all their data, and warns you about hidden programs such as crypto miners. Free and open source.

Install

Two ways to get Sentinel. Downloading is the quickest; building from source lets you read every line first.

Option 1 · Download (no Xcode, no clone)

A 2.5 MB universal app for Apple Silicon and Intel, macOS 14 or newer.

Download Sentinel.zip

  1. Double-click the zip, then drag Sentinel.app to Applications.
  2. First open only: macOS warns that it cannot check the app, because it is signed locally and not notarized. Right-click the app → Open → Open.
  3. Or remove the warning in Terminal: 
    xattr -dr com.apple.quarantine /Applications/Sentinel.app

Verify the download: SHA-256 checksum · all releases

Option 2 · Build from source

Needs macOS 14+ and Xcode 15+ (or the Swift toolchain).

git clone https://github.com/alfayedoficial/sentinel-mac.git
cd sentinel-mac
./build.sh
open ~/Applications/Sentinel.app

No git? Download the source as a zip, unzip it, and run ./build.sh inside the folder.

Updates: from version 1.1.0 Sentinel updates itself from GitHub Releases (verified checksum and signature, one click, can be switched off in Settings). Running 1.0.0? Download 1.1.0 once; it cannot update itself.

After opening: a small icon with your memory percentage appears in the menu bar. For the smoothest experience, open System Settings → Login Items & Extensions and switch on Sentinel (so it can switch off system launch items without asking for your password each time), and tick Open Sentinel at login in its Settings tab.

Honest limits. Threat Watch is a lookout, not an antivirus: it knows common miner names, mining-pool arguments, deleted executables, unsigned heavy programs in temporary folders and suspicious launch items. The app is signed locally and not notarized; Developer ID signing is on the roadmap.

Privacy and safety

Nothing leaves your Mac

No accounts, analytics or telemetry. The only network request is an optional update check against GitHub Releases, which you can switch off.

Review, then confirm

Every clean-up shows a list first. Items go to the Trash and can be restored from History.

A tiny, locked-down helper

The optional root helper can only switch off third-party launch items in two folders. It refuses Apple items and path tricks, and it never deletes.

Open source

MIT licensed. Read every line, change it, share it.

Contribute

Fix a typo, add a tool, write a detection rule or translate the app. There is a step-by-step guide, tests, and issues labelled good first issue.
